# 🎮 Number Guessing Game

A fun number guessing game built using HTML, CSS,
JavaScript and Node.js.

## Features
- Random number generation
- High and Low hints
- Attempt counter
- Win message
- Restart game
- Frontend and Backend separation

## Technologies
- HTML
- CSS
- JavaScript
- Node.js

## How to Run

1. Install Node.js.
2. Open terminal inside the project folder.
3. Run:

   cd backend
   node server.js

4. Open http://localhost:3000
